One-Way Quantum Symmetric Private Information Retrieval Protocol From A Single Database Server Using NISQ Devices

Authors: Xiang Zou, H. F. Chau
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.02093v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: quantum measurements 1/5

↔ Scroll figures horizontally

Summary. This paper presents a quantum protocol for Symmetric Private Information Retrieval (SPIR) that works even when the communicating parties are limited to noisy, memory-less NISQ devices. It achieves information-theoretic security by leveraging BB84 states and random permutations. This work is significant because it provides a practical, resource-constrained solution to a fundamental problem in quantum data access.

Why it may be interesting. The focus on NISQ constraints and the integration of quantum communication security with information retrieval makes it highly relevant for quantum optics and quantum information theorists designing practical quantum protocols.

Detailed structure

Main problem. The paper addresses the challenge of achieving Symmetric Private Information Retrieval (SPIR) from a single database server using quantum communication.

Main result. It demonstrates that provably secure QSPIR is possible under the strict constraint of NISQ devices, requiring only passive linear-optical measurements alongside standard QKD components.

Method. The protocol combines principles from Quantum Key Distribution (QKD) with cryptographic techniques like random permutations and hashing to ensure index privacy.

Model / system. The system utilizes single photons transmitting BB84 states over a one-way quantum channel. The security analysis is tailored for the NISQ regime, meaning no long-term quantum memory is assumed for the communicating parties.

Key observables. Secrecy against eavesdroppers, database privacy (quantified by an explicit size rule), and user privacy.

Important parameters / regimes. Database size ($10^4$-bit example), required database privacy ($10^{-6}$), and block size (around a thousand qubits).

Assumptions / limitations. The security proof assumes the eavesdropper is all-powerful, while the user and server are restricted to NISQ devices. The protocol is shown to work for single photons over a tolerated noise channel.

Figures summary. Figure 6 validates the effective Unambiguous State Discrimination (USD) rates against signal intensity ($\mu_1$) and transmittance ($\eta$), while Figure 7 compares measured conclusive counts for the honest receiver versus an adversary using Monte Carlo simulations.

Paper structure. The paper establishes the problem, details a multi-step protocol involving BB84 transmission, joint random permutation, and hashing. It then provides security proofs and validates the resource requirements using simulation and theoretical bounds.

Abstract

Symmetric private information retrieval (SPIR) lets an inquirer obtain one specific bit only, without leaking any information about its index to the database owner. With a single server, this is impossible for parties with unrestricted quantum power. We show that it becomes possible, with information-theoretic security, when the server and the user hold only noisy intermediate-scale quantum (NISQ) devices without long-term quantum memory and measure each qubit on arrival, while the eavesdropper remains all-powerful; this is a stricter form of the memory restriction of the bounded- and noisy-quantum-storage models. The server sends BB84 states one way; the user discriminates them unambiguously and so knows a random subset of the bits. After a joint random permutation into blocks, the user announces the conclusive locations of one privately chosen block, and the server hashes and takes a random parity of these locations in every block; the permutation makes it exponentially unlikely that one set of locations fits two blocks. We prove secrecy against the eavesdropper, database privacy through an explicit size rule for the announced set, and user privacy against a server who prepares the prescribed BB84 states and announces truthfully, exactly for single photons and up to a small multi-photon term over a tolerated noise channel. The only addition to BB84 equipment is a passive linear-optical measurement with one ancillary mode. For a $10^{4}$-bit database and database privacy $10^{-6}$, blocks of about a thousand qubits suffice over a tolerated noise channel for a user who applies the prescribed measurement; certifying an arbitrary memoryless user and committing to the permutation need larger auxiliary transmissions, which we quantify with finite keys. Database privacy extends to decoy-state weak coherent pulses, and simulations show that the bound is nearly tight.

Operational transformation rates of quantum states

Authors: Giulia Mazzola, Renato Renner
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.02025v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: quantum measurements 1/5

↔ Scroll figures horizontally

Summary. This work re-evaluates quantum resource theories by relaxing the strict assumption that multiple copies of a quantum state are independent and identically distributed. Using an operational viewpoint, the authors define resource sets based on what an experimentalist can measure. They introduce new asymptotic rates that quantify resource transformation capabilities under these realistic, imperfect conditions.

Why it may be interesting. It provides a rigorous, experimentally grounded framework for resource theories, moving beyond idealized mathematical assumptions to model real-world imperfections in quantum resource utilization.

Detailed structure

Main problem. The paper addresses the gap between assuming quantum states are independent and identically distributed (iid) when multiple copies are available, versus the operational reality where unknown defects or correlations might exist.

Main result. It develops operational analogues for asymptotic transformation rates (like entanglement cost) that account for the full, operationally defined class of resource states, rather than just the ideal iid case.

Method. The authors employ a de Finetti-type argument and define operational sets of states based on what an experimentalist can distinguish via tomography protocols.

Model / system. The system involves multiple copies of a quantum state $ ho$, leading to a joint $n$-system state $ ho(n)$. The focus is on characterizing the set of states $ ext{OP}( ext{tom}(\cdot); ho)$ that are indistinguishable from a tensor power state.

Key observables. Operational asymptotic transformation rates, entanglement cost, and distillation rates.

Important parameters / regimes. The number of copies $n$, and the deviation from the iid assumption (defects/correlations).

Assumptions / limitations. The definition of the operational set relies on the existence of a 'sensible' tomography protocol $ ext{tom}(\cdot)$.

Figures summary. Figure 1 shows that tomography cannot certify the joint state is exactly $ ho^{\otimes n}$. Figure 2 illustrates 'almost-iid states' showing the tensor power structure corrupted by defects/correlations. Figure 3 compares iid vs. operational rates.

Paper structure. The paper moves from identifying the limitation of the iid assumption in practice, to developing the operational framework using de Finetti arguments, and finally applying this framework to define and compare operational asymptotic rates.

Abstract

Typically, multiple copies of a quantum state are described by a tensor power of that state. However, from an operational point of view, an experimentalist cannot, in general, rule out imperfections at unknown positions or correlations between copies, so assuming independent and identically distributed (iid) copies is not justified a priori. In the following, we relax the iid assumption by considering a whole set of resource states that are fundamentally indistinguishable from a tensor power state, and in that sense look like many copies of the quantum state to the experimentalist. Using a de Finetti-type argument, we show that this operational set of states can asymptotically be represented by almost-iid states. As an application, we introduce operational analogues of asymptotic transformation rates, such as entanglement cost and distillation. This raises the question of whether these rates coincide with their iid counterparts.

Polynomial-time additive-error estimation of output probabilities for shallow quantum circuits

Authors: Matthew Coudron, Michael J. Gullans, Jon Nelson, Joel Rajakumar, Shi Jie Samuel Tan
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.02146v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: quantum measurements 1/5

↔ Scroll figures horizontally

Summary. This paper introduces a deterministic classical algorithm to estimate the output probability of shallow quantum circuits in polynomial time. It achieves this by employing a sophisticated combination of inclusion-exclusion principles and cluster expansion techniques. This result significantly advances the field by providing an efficient method to analyze quantum circuit outputs for arbitrary connectivity.

Why it may be interesting. This work provides a powerful classical tool to estimate quantum mechanical probabilities, which is crucial for simulating quantum circuits and understanding the complexity limits of quantum computation.

Detailed structure

Main problem. The paper develops a deterministic classical algorithm to estimate the output probability $P(x) = |\langle x|U|0^n angle|^2$ of a shallow quantum circuit $U$ to an additive error $\epsilon$. The goal is to achieve this estimation in time polynomial in $n$ and $1/\epsilon$.

Main result. A deterministic classical algorithm is presented that achieves polynomial-time estimation of the output probability for constant-depth quantum circuits with arbitrary connectivity, significantly improving upon prior state-of-the-art time complexities.

Method. The core method combines an inclusion-exclusion decomposition with a cluster expansion technique to bound errors arising from non-peaked regions. This allows the problem to be reduced to efficiently estimating marginal probabilities of 'good' output bits.

Model / system. The model is an $n$-qubit unitary quantum circuit $U$ characterized by constant depth and gates with bounded fan-in and arbitrary connectivity. The initial state is $|0^n angle$.

Key observables. The primary observable is the output probability $P(x) = |\langle x|U|0^n angle|^2$. Secondary observables include marginal probabilities $P(xS)$ for subsets $S$ of qubits.

Important parameters / regimes. Key parameters include $n$ (number of qubits), $\epsilon$ (additive error tolerance), and the circuit depth/connectivity structure.

Assumptions / limitations. The analysis relies on the structure of shallow circuits leading to bounded degree in the connectivity graph and assumes the ability to perform specific calculations (like marginal estimations) within derived polynomial bounds.

Figures summary. Figure 1 illustrates 'lightcones' bounding the probability of agreement. Figure 2 depicts a term in the inclusion-exclusion decomposition, separating contributions from 'good' and 'bad' bits.

Paper structure. The paper builds upon prior work by introducing a cluster expansion technique and an inclusion-exclusion argument. It decomposes the probability calculation based on 'bad' and 'good' output bits, leading to a final theorem establishing the polynomial-time algorithm.

Abstract

We give a deterministic classical algorithm that estimates $|\langle x|U|0^n\rangle|^2$ to additive error $\varepsilon$ in $\mathrm{poly}(n, 1/\varepsilon)$ time, where $U$ is a constant-depth quantum circuit comprised of gates with bounded fan-in and arbitrary connectivity, and $x$ is an arbitrary $n$-bit output string. This improves over prior state-of-the-art algorithms that takes $n^{O(log(n))}$ time for the same task, $n^{O(log(log(n))}$ when $U$ is geometrically local, and $n^{O(1)}$ for 2D geometrically-local circuits.

Smooth perturbation theory and generic Cantor spectrum for multi-dimensional monotone quasiperiodic operators

Authors: Ilya Kachkovskiy, Leonid Parnovski, Roman Shterenberg
Type: theory · Category: disordered systems and neural networks · PDF: https://arxiv.org/pdf/2610.00733v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: Frenkel-Kontorova 1/5

↔ Scroll figures horizontally

Summary. This theoretical paper analyzes the spectrum of multi-dimensional quasiperiodic Schrödinger operators defined by sawtooth-type potentials. Using advanced perturbation theory, the authors prove that for generic potentials, the spectrum is a Cantor set with all gaps open. This work provides deep mathematical insight into spectral rigidity and localization in deterministic, quasiperiodic media.

Why it may be interesting. The rigorous mathematical analysis of spectral gaps in quasiperiodic systems is central to understanding localization phenomena, which is a key topic in condensed matter physics, particularly concerning the transition between extended and localized states.

Detailed structure

Main problem. The paper investigates the spectral structure of multi-dimensional quasiperiodic Schrödinger operators, specifically determining when their spectrum forms a Cantor set.

Main result. For generic choices of the sampling function, the spectrum is proven to be a Cantor set with all gaps open, and this set of functions is a dense G_delta subset.

Method. The authors employ smooth perturbation theory, utilizing Rayleigh-Schrödinger expansions and analyzing the vanishing of eigenfunctions at the origin to diagnose the opening or closing of spectral gaps.

Model / system. The model is a quasiperiodic Schrödinger operator $H(x) = \varepsilon(\Delta + V(x))$ acting on $\ell^2(\mathbb{Z}^d)$, where the potential $V(n)$ is defined by a monotone sawtooth-type function $f$ sampled along a quasiperiodic lattice defined by $\omega$.

Key observables. The spectrum $\sigma(H)$, the status of spectral gaps (open/closed), and the value of the eigenfunction at the origin, $\psi_n(0, 0)$.

Important parameters / regimes. The small perturbation parameter $\varepsilon$ (or $\epsilon$), and the properties of the frequency vector $\omega$ (rationally independent).

Assumptions / limitations. The analysis is primarily restricted to the perturbative localization regime ($0 < \varepsilon < \varepsilon_0$), and the results distinguish between principal and non-principal gap behaviors.

Paper structure. The paper builds from establishing the basic model and perturbation framework (Chunk 1), develops the quantitative perturbation theory for gap analysis (Chunk 2), proves the density of functions yielding open gaps via constructive perturbations (Chunk 3), and concludes with convergence arguments for the limiting operators (Chunk 4).

Abstract

We consider multi-dimensional quasiperiodic Schrödinger operators with monotone sawtooth-type potentials in the perturbative localization regime. We prove that a given gap is closed iff a corresponding (via a natural gap labeling) eigenfunction vanishes at the origin. Using this, we show that for a generic choice of the sampling function $f$, the spectrum of such an operator is a Cantor set, with all possible gaps being open. We also provide a class of functions $f$ for which some gaps are closed. Finally, we observe that certain gaps are more difficult to close than the others.

Stationarity as a One-Mode Constraint on Quantum Correlation

Authors: Itai Panas
Type: theory · Category: strongly correlated electrons · PDF: https://arxiv.org/pdf/2610.02090v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: Keldysh / 2PI / non-Gaussian methods 1/5

↔ Scroll figures horizontally

Summary. This theoretical work argues that for quantum systems in stationary states, the terminal scalar correlation energy can be accurately described by a single, 'one-mode' constraint, even if the full microscopic excitation spectrum is complex. By testing this hypothesis on Helium using reg-HF methods against Bethe-Goldstone theory, the authors show that energetic sufficiency does not require spectral simplicity.

Why it may be interesting. It provides a rigorous theoretical tool to decouple the dimensionality required for calculating a specific, observable energy (the terminal state) from the complexity of the underlying quantum correlation structure, which is highly relevant for understanding correlation in strongly interacting systems.

Detailed structure

Main problem. The paper investigates whether the terminal scalar correlation-energy response of a quantum system, particularly in stationary states, must retain the full dimensionality of its microscopic response.

Main result. Stationarity imposes a 'one-mode constraint' on the terminal scalar correlation response, which is shown to be highly accurate even when the full microscopic excitation spectrum (as seen in Bethe-Goldstone calculations) is complex and multi-dimensional.

Method. The authors use a regularized Hartree-Fock (reg-HF) construction, employing Gaussian measures and virial completion, and contrast these results against exact calculations like Bethe-Goldstone (BG) theory.

Model / system. The primary test case is the Helium atom/ion system. The theoretical framework involves analyzing the correlation energy derived from the Hamiltonian under the constraint of a stationary state.

Key observables. Terminal scalar correlation response ($\Delta^{(1)}_0$), Bethe-Goldstone pair correlation energy ($E_{ ext{BG}}^c$), and the diagnostic quantity $W_{BG}$ which measures spectral complexity.

Important parameters / regimes. The residual dimensionless parameter $\delta$, the retained Coulomb carrier $\delta/e$, and the finite-$Z$ insertion ratio $8\delta/9$.

Assumptions / limitations. The core hypothesis is the 'one-mode exclusion axiom,' which assumes that covariance components orthogonal to the retained pair mode are excluded from the terminal energy property.

Figures summary. Figure 2 compares the absolute error of the one-mode He-like correlation energies against the BG spectral-width diagnostic $W_{BG}$, demonstrating a clear separation between energetic sufficiency and spectral simplicity.

Paper structure. The paper develops the argument by first establishing the reg-HF framework and the one-mode constraint imposed by stationarity. It then tests this constraint using Helium, comparing the resulting single-mode energy calculation against the full, complex spectrum derived from Bethe-Goldstone theory.

Abstract

A stationary quantum state has one dynamical phase factor and one scalar energy even when its internal response spans a large Hilbert space. Our argument concerns not the value or observability of an absolute phase, but the one-ness of stationary time evolution. In regularized Hartree--Fock (reg-HF), the connection to the stationary mean field is established before any one-mode reduction: the primitive-product relative-coordinate Gaussian measure induced by the Gaussian HF representation fixes a covariance and, at that covariance, is simultaneously the minimum-Fisher-information and maximum-Shannon-differential-entropy distribution and the equality case of the Stam bound. The Coulomb operator admits a compatible Gaussian scale resolution, and virial completion converts the resulting regularized pair displacement into a stationary-compatible response. Stationarity motivates a one-mode constraint on the terminal scalar correlation response. The decisive reg-HF hypothesis is a one-mode exclusion axiom: covariance carried by response components orthogonal to the retained pair mode is excluded from the terminal scalar energy property, without asserting that the unrestricted response is one dimensional. Helium provides the minimal nontrivial test. The parameter-free retained Coulomb carrier $-δ/e$ and finite-$Z$ insertion $8δ/9$ closely reproduce independent He-like coefficients and energies, while an explicit Bethe--Goldstone calculation displays a broad non-single-denominator return spectrum even though its scalar energy is exactly moment-compressible. The result separates microscopic spectral complexity from one-mode energetic sufficiency.

Zero- Versus Infinite-Temperature Damping in Variational Quantum Circuits: Feature Scale, Sampling Cost, and Frame Gauge

Authors: Vu-Quoc-Minh Nguyen, Tuan-Vu Truong, Hoang-Long Nguyen, Trung-Khanh Le
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.01466v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: correlated / nonlocal dissipation 1/5

↔ Scroll figures horizontally

Summary. This work rigorously compares amplitude damping (zero-temperature noise) against its Pauli twirl counterpart (infinite-temperature noise) in Variational Quantum Circuits. The study finds that while the noise models look similar in theory, the practical impact on measurement fidelity is vastly different, with AD maintaining significantly better performance in finite-shot simulations. This highlights the critical importance of understanding the precise thermal nature of noise in quantum computation.

Why it may be interesting. The explicit comparison between zero-temperature (AD) and infinite-temperature (Pauli twirl) noise provides deep insight into the physical origin of noise biases in quantum machine learning algorithms, which is crucial for designing robust quantum hardware.

Detailed structure

Main problem. The paper compares the effects of zero-temperature amplitude damping (AD) versus infinite-temperature Pauli twirl noise on the performance of Variational Quantum Circuits (VQC). It investigates how this noise affects feature scale, sampling cost, and the underlying gauge structure.

Main result. While a trainable output scale can mitigate accuracy differences in ideal simulations, the noise difference reappears as a significant cost in finite-shot measurements, with AD performing substantially better than its twirled counterpart. The damping direction is shown to be a gauge under specific circuit conditions.

Method. The authors use theoretical analysis and numerical simulations to compare noise channels (AD vs. Pauli twirl) applied to VQCs used for tasks like classification and eigensolving.

Model / system. The core model is the Variational Quantum Circuit (VQC), applied to tasks such as 4-qubit classification (on MNIST data) and quantum eigensolvers. Noise is modeled using Amplitude Damping (AD) and its infinite-temperature counterpart, the Pauli twirl.

Key observables. Test accuracy retention, operational shot cost ($\kappa(N)$), feature scale, and the relative error in eigensolver calculations.

Important parameters / regimes. Damping parameter ($p$), circuit depth ($L$), number of qubits ($n$), and the number of measurement shots ($N_s$).

Assumptions / limitations. The analysis compares AD to the Pauli twirl approximation, and some results rely on specific averaging assumptions for the final circuit block.

Figures summary. Figures compare performance metrics (like accuracy vs. depth) under different noise channels, demonstrating the quantitative difference in performance between AD and Pauli twirls, especially when considering measurement shot costs.

Paper structure. The paper systematically compares AD and Pauli twirl noise, first analyzing feature scale differences, then quantifying the performance gap in finite-shot simulations, and finally discussing the gauge nature of the damping direction in different circuit contexts.

Abstract

The Pauli twirl of amplitude damping (AD) is generalized amplitude damping at infinite temperature: it keeps the contraction of AD and removes its non-unital term, so comparing the two in variational circuits isolates the zero-temperature bias, which acts mainly through the scale of the features. For random parameters, features under AD settle on a floor, which at strong damping is set by the last layer, has a closed form, and at fixed $T_1$ falls with temperature as $\tanh(\hbarω/2k_BT)$; under the twirls they shrink by a constant factor per layer, up to eight qubits. A trainable output scale removes most of the resulting accuracy differences, leaving AD ahead of its twirls by at most about three percentage points in our simulations; what it removes reappears as a cost in measurement shots: trained and tested with $10^3$ shots per image, a four-qubit classifier under AD at $p=0.3$ stays within 1.5 points of noiseless accuracy, while the twirled classifiers lose up to 33. At weaker damping the separation depth grows roughly as $(np)^{-1}\ln(1/p)$. The damping direction is a gauge when the damping follows complete entangling layers and the circuit boundaries are trainable; in an eigensolver it becomes physical inside a decomposed two-qubit gate.

(A Variant of) Clifford Circuit Synthesis is NP-Complete

Authors: Luna Lima Keller, Richard Kueng
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.02029v1
Analysis basis: full PDF text, analyzed in chunks

↔ Scroll figures horizontally

Summary. This paper establishes that finding the shortest quantum circuit representation for a given Clifford unitary is NP-hard. It achieves this by reducing the problem to graph edge coloring. Furthermore, it proves that for 3-regular graphs, the optimal circuit depth is determined solely by the number of CZ gates required, regardless of the inclusion of other Clifford gates like Hadamard or CNOT.

Why it may be interesting. This work provides deep complexity-theoretic bounds on quantum hardware design, showing that even for the relatively simple Clifford group, finding the shortest circuit is computationally hard.

Detailed structure

Main problem. The paper investigates the computational complexity of optimal quantum circuit synthesis, specifically for Clifford circuits.

Main result. It proves that optimal Clifford circuit synthesis is NP-hard, and furthermore, for 3-regular graphs, the optimal depth using general Clifford gates equals the depth achievable using only CZ gates.

Method. The hardness proof uses a reduction from 3-edge colorability on 3-regular graphs to the circuit synthesis problem. The equivalence proof relies on systematically eliminating Hadamard and CNOT gates from the optimal circuit structure.

Model / system. The model is the quantum circuit implementing a unitary $U_G$ derived from a graph $G$. The analysis focuses on the Clifford group operations using elementary gates like H, CNOT, and CZ.

Key observables. Optimal circuit depth ($ ext{Delem}(U_G)$), edge chromatic number ($\chi'(G)$), and the number of CZ gates ($NCZ$).

Important parameters / regimes. The graph $G$ is assumed to be 3-regular, constraining $\chi'(G)$ to $\{3, 4\}$. The analysis often considers circuits of depth $\le 3$.

Assumptions / limitations. The analysis assumes that gates on disjoint qubits can be executed in parallel in a single layer, and the final structural proofs are restricted to 3-regular graphs.

Figures summary. Figure 1 illustrates the reduction from 3-regular graph edge coloring to depth-optimal Clifford circuit synthesis, akin to a Karp reduction.

Paper structure. The paper first establishes the NP-hardness via reduction from graph coloring. It then proceeds to prove the structural equivalence ($ ext{Delem} = ext{DCZ}$) by sequentially simplifying the circuit structure, first eliminating Hadamard gates, then CNOT gates, leaving only CZ gates for 3-regular graphs.

Abstract

Optimal circuit synthesis is the problem of finding the shortest-depth circuit representation of a given functionality with respect to a pre-specified elementary gate set. This is a central problem in both quantum and classical hardware design. While the classical version is very well understood -- both in terms of heuristics and rigorous hardness assertions -- much less is known about optimal quantum circuit synthesis. We focus on optimal Clifford circuit synthesis, for which various heuristics are known, e.g. via reduction to 3-SAT. Our main result supplies a matching hardness result: a variant of optimal Clifford synthesis is NP-hard. The proof proceeds in two parts: (i) reduce 3-edge colorability on 3-regular graphs to a circuit synthesis problem that only involves CZ gates, (ii) prove that the availability of additional elementary Clifford gates -- most notably: Hadamard, phase and CNOT -- cannot lead to further improvements of the optimal circuit depth. Our work sharpens the complexity-theoretic understanding of Clifford circuits: simulation and equivalence checking are in P, whereas deciding whether a Clifford unitary admits an implementation within a prescribed depth is NP-complete.

↔ Scroll figures horizontally

Summary. This theoretical paper generalizes the quantum Stein lemma to arbitrary von Neumann algebras, providing rigorous bounds for distinguishing between quantum states. It proves that the rate of distinguishability is governed by the regularized relative entropy, establishing a sharp threshold for testing quantities. This extends fundamental results from finite quantum systems to the most general setting of operator algebras.

Why it may be interesting. While highly abstract, the techniques involving relative entropy rates and strong converse theorems are foundational to understanding the limits of quantum channel capacity and distinguishability, which are core concepts in quantum information theory.

Detailed structure

Main problem. The paper aims to prove a generalized quantum Stein lemma for hypothesis testing involving i.i.d. normal states against convex, tensor-stable families on arbitrary von Neumann algebras.

Main result. It establishes that the asymptotic worst-case type-II error exponent is achieved by the regularized relative entropy, providing a strong converse for the distinguishability rate.

Method. The proof combines integral representations of relative entropy (via hockey-stick divergences), a modular testing bound, and convex minimax arguments.

Model / system. The theory is developed for quantum states ($ ho, \sigma$) defined on arbitrary von Neumann algebras ($M$), generalizing results from finite-dimensional systems.

Key observables. The worst-case type-II error exponent, the regularized relative entropy ($R$), and the composite hockey-stick quantities ($Q_n(r)$).

Important parameters / regimes. The error tolerance $\epsilon \in (0, 1)$ and the number of tensor factors $n o \infty$.

Assumptions / limitations. The family of states $F$ must be convex and tensor-stable, and the existence of an alternative state with finite relative entropy from the null state is assumed.

Figures summary. Not specified.

Paper structure. The paper builds by defining key divergences and bounds (relative entropy, modular testing bound), proving convergence results for testing profiles (Proposition 3.1), establishing the sharp threshold for $Q_n(r)$, and finally deriving the strong converse and fixed-error rate upper bound (Theorem 1.2).

Abstract

We prove a generalized quantum Stein lemma for i.i.d. normal states against convex, tensor-stable families on arbitrary von Neumann algebras. Assuming the existence of an alternative state with finite relative entropy from the null state, we show that, at every type-I error tolerance $\varepsilon\in (0,1)$, the worst case type-II error exponent is achieved with the regularized relative entropy with a strong converse. The proof combines the integral representation of relative entropy by hockey-stick divergences, a modular testing bound, and convex minimax argument.

An exponential separation between entanglement-assisted and unassisted one-way quantum communication

Authors: Ryan Anselm, Srijita Kundu, Olivier Lalonde, Ashwin Nayak
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.02099v1
Analysis basis: full PDF text, analyzed in chunks

Summary. This paper resolves a long-standing open problem by proving an exponential separation in the one-way quantum communication setting. They demonstrate that certain total Boolean functions can be computed using very few classical bits if entanglement is shared, but require significantly more quantum qubits if entanglement is unavailable. This result highlights the computational advantage of entanglement for total functions.

Why it may be interesting. It provides a concrete, quantifiable separation in quantum communication complexity, which is a fundamental theoretical tool used to understand the power of entanglement in computation, relevant to quantum networking and information theory.

Detailed structure

Main problem. The paper addresses the open question of whether an exponential separation exists between the communication complexity required for a total Boolean function when entanglement is available versus when it is not, specifically in the one-way communication setting.

Main result. The authors establish an exponential separation by constructing a family of total Boolean functions $f_n$ that require only $O(\log n)$ bits of one-way classical communication with prior entanglement, but $\Omega(n^{1/3})$ qubits without entanglement.

Method. The proof involves establishing upper and lower bounds on the communication complexity for the function, utilizing techniques from quantum communication complexity theory and relating the problem to the subgroup membership problem.

Model / system. The model is the one-way quantum communication setting for computing a total Boolean function $f_n: \{0, 1\}^n imes \{0, 1\}^n o \{0, 1\}$, comparing protocols that use shared entanglement versus those that do not.

Key observables. Communication cost (bits vs. qubits), success probability, and the separation gap (exponential vs. polynomial).

Important parameters / regimes. The function size $n$, the communication complexity bounds ($O(\log n)$ vs. $\Omega(n^{1/3})$), and the error tolerance ($\le 1/3$).

Assumptions / limitations. The result holds for a family of total Boolean functions, and the lower bound techniques rely on specific mathematical principles like Yao's min-max principle.

Paper structure. The paper first frames the open question regarding total Boolean functions. It then establishes the upper bound using entanglement-assisted protocols (related to subgroup membership) and derives the lower bound for the unassisted quantum setting, culminating in the proof of the exponential separation.

We characterize how the presence of this on-site Gaussian disorder reduces $T_c$ across the second order transition line, and discuss how our results suggest that $T_c$ remains finite even at large values of $σ$. We also determine the effects of disorder on the tricritical point of the conventional, uniform, Blume-Capel model, finding that it significantly suppresses the first-order phase transition, eliminating it entirely at large values of $σ$.

Efficiently Optimizing the Quantum Value of Bell Inequalities using Batched Gradient Descent

Authors: Xinyu Xu, Ping Zhu, Weikang Li, Pierre Pocreau, Dalu Ding, Dawei Ding

Summary. This paper presents a novel Batched Gradient Descent (BGD) optimizer designed to efficiently calculate the quantum value of complex Bell inequalities. By using direct tensor contraction, BGD overcomes the scaling limitations of previous methods, allowing analysis of systems with thousands of inputs or outputs. Why it may be interesting. The development of scalable optimization tools for Bell inequalities is crucial for testing fundamental principles of quantum mechanics and designing quantum communication protocols.

Main result. The authors introduce a Batched Gradient Descent (BGD) optimizer that efficiently computes the quantum value for large-scale Bell inequalities, achieving significant speedups over existing methods.

Abstract

Exploring the world of Bell inequalities requires numerical methods that scale effectively with the number of parties, inputs, and outputs. Such methods can be used to study large-scale Bell inequalities beyond the reach of analytic methods, to design experiments for violating more complicated Bell inequalities, and to enable applications of Bell inequality violation. Such applications include randomness generation and multi-agent coordination with restricted communication. However, current general purpose optimizers such as the see-saw method struggle to handle Bell inequalities with only a dozen inputs and outputs. We introduce an optimizer for the quantum value of a Bell inequality based on batched gradient descent (BGD). More precisely, our BGD optimizer is a differentiable search over feasible quantum strategies in which states and projective measurements are generated from unconstrained variables. The Bell expression is evaluated by a direct tensor contraction without forming the prohibitively large Bell operator. This formulation makes parallel random restarts inexpensive and is thus naturally implemented by a GPU. We evaluate our optimizer against the see-saw method and find a significant speedup for a wide variety of Bell inequality families. Implemented on a GPU, our BGD optimizer can optimize Bell inequalities in our numerical experiments with more than a thousand inputs or outputs within minutes. For these large-scale Bell inequalities, we also efficiently compute the classical value by enumerating possible strategies using a GPU or expressing the optimization as a mixed-integer linear program. Our optimizers can serve as numerical evaluation tools for Bell experiments and multi-agent coordination problems modeled by Bell inequalities with many inputs and outputs, a common feature of real-world scenarios such as high frequency trading and distributed systems.
