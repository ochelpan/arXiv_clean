Magnonic Combinatorial Memory based on a network of coupled active ring circuits

Authors: Mykhaylo Balinskiy, Paulo Julio, Jeffrey Vargas, Diana Bisono Balaguer, Jacob Greenstein, Alexander Khitun
Type: both · Category: other · PDF: https://arxiv.org/pdf/2608.28457v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: driven-dissipative phase transition 3/5 · methods for driven-dissipative 2/5 · non-equilibrium universality 2/5 · Keldysh / 2PI / non-Gaussian methods 1/5 · analog quantum simulation 1/5 · correlated / nonlocal dissipation 1/5

Summary. This paper proposes a Magnonic Combinatorial Memory (MCM) that stores data by controlling the auto-oscillation state within a network of coupled active ring circuits. The system demonstrates a quadratic scaling of storage capacity with the number of coupled units, achieving high contrast ratios in experiments. It represents a solid-state approach to high-density, non-volatile memory using magnonics.

Why it may be interesting. The use of coupled, non-linear, dissipative systems (ARCs) to store classical information via collective oscillation states provides a rich platform for studying non-equilibrium dynamics and complex state spaces, relevant to open quantum systems.

Detailed structure

Main problem. The paper addresses the development of a novel, high-density memory device, the Magnonic Combinatorial Memory (MCM), whose information storage capacity scales quadratically with the number of coupled circuits.

Main result. Experimental demonstrations using three coupled active ring circuits achieved a 27-bit binary response pattern with a robust On/Off ratio exceeding 30 dB at room temperature.

Method. The research combines theoretical modeling of coupled oscillator dynamics (using transfer matrices and spectral radius) with experimental characterization of magnonic circuits.

Model / system. The system is based on a network of coupled Active Ring Circuits (ARCs) utilizing spin waves propagating in a Yttrium Iron Garnet (YIG) film. Information is encoded in the auto-oscillation state (presence/absence) determined by the phase and frequency settings of the coupled circuits.

Key observables. Auto-oscillation power (On/Off ratio), spectral radius ($ ho(T)$), and the number of accessible phase combinations (bits).

Important parameters / regimes. Quadratic scaling of bits with the number of circuits ($O(N^2)$); On/Off ratio > 30 dB; Room temperature operation.

Assumptions / limitations. The coupling mechanism is assumed reciprocal, and the analysis often relies on linearizing the dynamics or assuming independent control over coupling coefficients.

Figures summary. Figures illustrate schematics of single and coupled ARCs, phase maps showing oscillation regions, and experimental data correlating phase settings with measured circulating power.

Paper structure. The paper progresses from defining the MCM concept and its components (ARCs, coupling) to theoretical modeling of coupled dynamics, presenting experimental validation using multiple coupled circuits, and concluding with a discussion of scalability and limitations.

Abstract

Magnonic Combinatorial Memory (MCM) is a type of memory where the bits of information are encoded in the signal propagation paths in the network. In this work, we consider MCM based on the network of a coupled active ring circuit (ARC). Each circuit includes a broadband amplifier, a magnonic delay line, an adjustable frequency filter, an adjustable phase shifter, and a power detector. The coupling between the circuits is via spin waves propagating in the common delay line - ferrite film. There may or may not be auto-oscillations in the active ring circuits, depending on the combination of circuit parameters and circuit coupling. The address of MCM is defined as the combination of the states of the phase shifters and frequency filters, while the MCM state is defined as the presence/absence of the auto-oscillations. The coupling between the circuits is achieved by placing micromagnets on top of the ferrite film. The number of bits that can be encoded in the network increases quadratically with the number of coupled circuits. This scaling provides a fundamental advantage over conventional memory. We present experimental data obtained for three magnonic ARCs connected via a single-crystal yttrium iron garnet Y3Fe2(FeO4)3 (YIG) film. The data illustrate an example of encoding a 27-bit binary response pattern, corresponding to the 27 experimentally accessible phase combinations. The results demonstrate a robust operation of MCM with an On/Off ratio exceeding 30 dB at room temperature. The advantages and shortcomings of the proposed approach are discussed.

Summary. This paper introduces ScatterWorks, an open-source Python package designed to model and solve quantum transport problems in complex network geometries. It allows researchers to build systems using modular operations and calculate key observables like conductance and quasienergies. This tool is particularly valuable for studying disordered and topological systems where analytical solutions are intractable.

Why it may be interesting. The package provides a powerful, general-purpose tool for calculating transport properties in complex quantum structures, which is highly relevant for studying open quantum systems and mesoscopic physics.

Detailed structure

Main problem. The paper addresses the need for a flexible and unified computational framework to study non-interacting transport and wave-propagation phenomena in complex, disordered, and topological quantum systems.

Main result. The authors introduce ScatterWorks, a Python package that successfully models and solves transport problems for systems like the Chalker-Coddington model, recovering expected critical behavior.

Method. The package builds networks using composable transformations (tile, cut, union) and assembles local scattering matrices into a global scattering operator, which is then solved using Schur-based linear algebra techniques.

Model / system. The models studied are general scattering networks, applicable to disordered systems, topological insulators, and moiré lattices. Examples include the Fabry-Perot interferometer and the Chalker-Coddington model describing the quantum Hall transition.

Key observables. Quasienergies, conductance (G), effective scattering matrix (S_eff), transmission (t), and reflection (r) coefficients.

Important parameters / regimes. The critical point parameter ($ heta_c = \pi/4$) for the quantum Hall transition, and the system size ($L$) governing computational scaling.

Assumptions / limitations. The derivation of the effective scattering matrix assumes that the internal scattering block ($\mathbf{S}_{ ext{bb}}$) does not have an eigenvalue of one, preventing singularity.

Figures summary. Figures illustrate the structure of the global scattering matrix, the basic setup of a Fabry-Perot interferometer, and the tiled structure of the Chalker-Coddington network, showing conductance vs. disorder parameter.

Paper structure. The paper details a systematic workflow: defining the base network, modifying it using operations (tile, cut, union, relink), compiling the global scattering operator, and finally solving for transport observables using Schur complements.

Abstract

Network models provide an efficient framework for studying non-interacting transport and wave-propagation phenomena in disordered and topological systems. We introduce ScatterWorks, an open-source Python package for building and solving network models. The package uses a compact network representation with composable transformation operations (tile, cut, relink, and union) to enable flexible construction of periodic and finite networks. Local scattering matrices on nodes can be assigned by node labels or explicit indexing, assembled into global scattering equations, and used to compute quasienergies and transport observables. The package supports sparse scattering matrices, allowing transport observables to be evaluated with Schur-based solvers. We demonstrate the package workflow on a symbolic Fabry-Perot interferometer and a numerical Chalker-Coddington model, recovering analytical expressions and the expected near-critical transport behavior of the quantum Hall transition. Plotting utilities with label-aware rendering are included to streamline debugging and reproducible setup for larger, custom network geometries.

Electrically Tunable Two-Component Exciton Condensate in a Coulomb-Coupled Graphene Trilayer

Summary. This work reports on the realization of an electrically tunable two-component exciton condensate in a graphene trilayer. By combining quantum capacitance measurements with advanced mean-field theory, the authors demonstrate that the condensate's internal structure can be continuously controlled by electrostatic gating. This provides strong evidence for a highly controllable, correlated excitonic phase in solid-state matter.

Why it may be interesting. The ability to electrically tune the internal structure of a correlated quantum state (the exciton condensate) provides a clean platform to study the interplay between external control parameters and emergent many-body symmetries, relevant to understanding correlated phases in artificial lattices.

Detailed structure

Main problem. To realize and study the continuously tunable internal structure of a two-component exciton condensate in a solid-state system, moving beyond systems where component properties are fixed by material chemistry.

Main result. The experiment confirms the existence of a two-component exciton condensate with a continuously tunable internal structure, supported by the observation of persistent quantum Hall states and the continuous rotation of condensate mode composition.

Method. The study combines quantum-capacitance measurements (experimental) with Hartree-Fock and Time-Dependent Hartree-Fock calculations (theoretical) to analyze collective excitations.

Model / system. The system is a graphene trilayer with negligible interlayer tunneling, supporting excitons bound by Coulomb interaction. The condensate is modeled as having two independent relative U(1) symmetries.

Key observables. Quantum capacitance ($C_P, C_G$), charge-incompressible quantum Hall states ($ u_{ ext{total}}=1, 2$), phase-stiffness eigenmodes, and Goldstone mode dispersions.

Important parameters / regimes. Layer-specific carrier densities ($ u_t, u_m, u_b$), total filling factors ($ u_{ ext{total}}$), and applied electrostatic gating voltages.

Assumptions / limitations. The analysis assumes negligible single-particle tunneling between layers and relies on mean-field approximations (Hartree-Fock).

Figures summary. Figures illustrate schematics of single- and two-component condensates, quantum capacitance measurements showing QHS states, and 3D scans mapping incompressibility across the layer-filling space.

Paper structure. The paper establishes the physical platform and experimental control, uses quantum capacitance to map out incompressible states, and then employs theoretical calculations (HF/TDHF) to characterize the resulting two-component condensate modes and their continuous tunability.

Abstract

Multicomponent condensates possess internal phase degrees of freedom unavailable to a single-component condensate, yet their components are rarely controllable in solids. Here we realize a graphene trilayer with negligible interlayer tunnelling in which the layer-specific carrier densities are continuously tuned by electrostatic gating. Quantum-capacitance measurements demonstrate that charge-incompressible quantum Hall states at total filling factors 1 and 2 persist across the full range of layer-filling configurations and continuously connect the three bilayer exciton-condensate limits. This persistence provides evidence for a trilayer excitonic state. Static Hartree-Fock and time-dependent Hartree-Fock calculations yield two independent finite phase-stiffness eigenmodes and two linearly dispersing Goldstone modes, respectively, when all three layers are partially filled, whereas only one phase-stiffness eigenmode and one linear Goldstone mode remain when one layer is unfilled. The stiffness eigenmodes rotate continuously between the two adjacent-layer exciton bases as charge is transferred among the layers, revealing electrical control of the condensate-mode composition. Together, the experimental and theoretical results support the identification of a two-component exciton condensate with a continuously tunable internal structure.

Two-dimensional quantum Griffith singularity in three-dimensional ZrN$_x$ superconducting films

Authors: Zi-Yan Han, Li-Min Yu, Yu-Cheng Cong, Yang Yang, Zhi-Xiang Sun, Zhi-Qing Li
Type: experiment · Category: disordered systems and neural networks · PDF: https://arxiv.org/pdf/2608.28166v1

Summary. This work experimentally demonstrates the presence of a 2D quantum Griffiths singularity in bulk 3D superconducting films ($ ext{ZrN}_x$). By analyzing magnetoresistance scaling, the authors show that the transport properties near the quantum phase transition are dominated by 2D-like rare regions formed by intrinsic defects. This highlights that disorder-induced inhomogeneity can dictate the critical scaling behavior, even in ostensibly higher-dimensional superconductors.

Why it may be interesting. The discrepancy between the macroscopic 3D nature and the observed 2D critical scaling provides a concrete experimental realization of how disorder can induce lower-dimensional critical behavior in a higher-dimensional material, which is relevant to understanding quantum critical points in disordered quantum systems.

Detailed structure

Main problem. The study reports the experimental observation of a two-dimensional (2D) quantum Griffiths singularity (QGS) in superconducting films that are macroscopically three-dimensional (3D).

Main result. Despite the 3D superconducting nature, the magnetoresistance isotherms exhibit power-law scaling characteristic of 2D systems, indicating that disorder-induced rare regions govern the critical behavior near the quantum phase transition.

Method. The research utilized low-temperature electrical transport measurements, specifically analyzing magnetoresistance isotherms ($ ho$ vs. $B$) and resistivity scaling near the superconductor-insulator transition.

Model / system. The physical system is epitaxial $ ext{ZrN}_x$ superconducting films ($\sim 200$-nm-thick) with a rock-salt structure. The underlying physics is governed by quenched disorder from intrinsic defects (vacancies, interstitials) creating spatially inhomogeneous superconducting rare regions.

Key observables. Magnetoresistance isotherms, effective critical exponent $z u$, and resistivity data near the superconductor-insulator transition.

Important parameters / regimes. Nitrogen concentration ($x \gtrsim 1.30$), magnetic field ($B$), and temperature ($T$).

Assumptions / limitations. The analysis assumes that the dynamics of the superconducting rare regions effectively behave as 2D systems near the quantum critical point, despite the bulk material being 3D.

Figures summary. Figures show XRD patterns confirming the rock-salt structure, and resistivity vs. temperature/field measurements used to extract scaling exponents.

Paper structure. The paper presents experimental characterization (XRD, EDS), followed by transport measurements ($ ho(T, B)$), analysis of superconducting coherence lengths, and finally, the core argument comparing the observed 2D scaling behavior against the expected 3D behavior near the QPT.

Abstract

We report the experimental observation of two-dimensional (2D) quantum Griffiths singularity (QGS) in $\sim$200-nm-thick epitaxial ZrN$_x$ superconducting films. The films possess a rock-salt structure and are three-dimensional (3D) with respect to superconductivity. For each film with $x \gtrsim 1.30$, the low-temperature magnetoresistance isotherms under fields perpendicular and parallel to the film plane cross over at a broad magnetic field range independently rather than at a single crossing point. Despite the macroscopic 3D nature of the superconductivity, the magnetoresistance isotherms at selected adjacent temperatures follow the theoretical prediction of power-law scaling for 2D superconducting systems, rather than that for 3D systems. The effective critical exponent $zν$, obtained by analyzing the magnetoresistance isotherms using the 2D power-law scaling, increases with decreasing temperature and diverges as the quantum phase transition is approached. In addition, the resistivity data near the superconductor-insulator or superconductor-metal transitions obey an activated scaling form that describes the quantum phase transition of 2D superconducting systems governed by an infinite-randomness critical point. The QGS in the ZrN$_x$ films is attributed to quenched disorder induced by intrinsic defects, such as Zr vacancies and N interstitials, which creates spatially inhomogeneous superconducting rare regions. The dynamics of these rare regions, which may exhibit effective 2D characteristics near the quantum critical point, dominate the transport properties of the system near the quantum phase transition. Our results provide compelling evidence for the existence of QGS in 3D superconductors and highlight the crucial role of disorder-induced inhomogeneity in determining the critical behavior of quantum phase transitions.

Summary. This work investigates Conway's Game of Life on complex crystal lattices, discovering robust structures like glider guns. Abstract

I explore Conway's Game of Life (GoL) on six composite Archimedean lattices. On the Kagome lattice, on which small gliders and puffers appear particularly frequently across inputs, I use the output of a symmetry-constrained evolutionary search algorithm to construct a novel glider gun. The glider gun comprises four interacting bouncers and stably emits a small glider every 276th generation. Serving as an extension of classical GoL, I also propose cells with a phase degree of freedom and an associated local phase rule, which on the Kagome lattice is demonstrated to host phase-periodic gliders. This enables the possibility of phase-sensitive and interference-based computations.

Summary. This work develops a theoretical framework to model how polymer coatings inside mesopores control the passage of colloids. By treating the process as an electrical resistance problem, the authors show that polymer attraction can enhance, rather than just impede, transport. This provides a physical basis for understanding highly selective biological barriers like the Nuclear Pore Complex.

Why it may be interesting. While focused on soft matter transport, the use of resistance/conductivity analogies to model diffusion in complex, confined media touches upon non-equilibrium statistical mechanics and transport phenomena relevant to open quantum systems.

Detailed structure

Main problem. The study investigates how polymer filling within mesopores affects the rate and selectivity of colloid permeation, aiming to explain the exquisite permselectivity observed in Nuclear Pore Complexes (NPCs).

Main result. The theoretical framework demonstrates that polymer filling can enhance transport beyond bare pores by maximizing colloid capture, providing a rational design strategy for separation devices.

Method. The authors employ theoretical methods, reformulating the diffusion problem into calculating the total electrical resistance of a medium with position-dependent resistivity.

Model / system. The model uses a cylinder-shaped mesopore filled with a polymer brush, drawing inspiration from the biophysical system of the NPC. Transport is governed by the Smoluchowski equation, treated via electrical analogy.

Key observables. Stationary diffusive flux (j), total pore resistance (R), and the partition coefficient (P) for colloids.

Important parameters / regimes. Polymer grafting density ($\sigma$), degree of polymerization ($N$), Flory-Huggins parameter ($\chi$), and colloid diameter ($d$).

Figures summary. Figures illustrate the schematic of colloid transport through a polymer brush-filled pore and show theoretical predictions mapped against experimental data for NPC translocation.

Paper structure. The paper progresses from defining the physical system (polymer-filled mesopores/NPCs) to establishing the governing mathematical framework (electrical analogy for diffusion) and finally applying this theory to derive quantitative relationships for transport rates and selectivity.

Abstract

Polymer-functionalised mesopores are an emerging technology for colloid separation, sensing and delivery. Their potential is strikingly illustrated in living cells, where nuclear pore complexes (NPCs) control biocolloid transport between the nucleus and the cytosol. Even colloids much smaller than the biopolymer-filled NPC channel are effectively blocked, but some larger colloids with distinct surface features rapidly permeate. Simplistically, one may expect any polymer filling to obstruct and slow down colloid transport. We demonstrate how a polymer filling that attracts colloids and extends beyond the mesopore, thus maximizing colloid capture, can instead increase permeation compared to a bare pore. We also define how polymer-filled mesopores can effectively gate colloids according to their size and surface features. Our findings provide a basic physical explanation for the exquisite permselectivity of NPCs, and a rational design strategy for novel mesopore-based separation, sensing, catalysis and drug delivery devices with enhanced performance features.

Summary. This theoretical study uses DFT to map the phase competition between ferroelectric and antiferroelectric states in LiTaO3. By analyzing the free energy under varying electric boundary conditions, the authors pinpoint a second-order phase transition at a specific critical electric displacement. This work is significant because it predicts an experimentally accessible pathway for switching between these two technologically relevant phases.

Why it may be interesting. While focused on condensed matter ferroelectrics, the methodology of mapping phase stability via free energy minimization under external fields (D) is a general technique applicable to understanding phase transitions in complex quantum or many-body systems.

Detailed structure

Main problem. The study investigates how competing ferroelectric (FE) and antiferroelectric (AFE) phases in LiTaO3 are selected by external electric boundary conditions.

Main result. The system undergoes a second-order FE-AFE phase transition at a critical electric displacement D_c = 0.051 C/m^2, which is more accessible experimentally than in similar materials.

Method. The research employs first-principles Density Functional Theory (DFT) calculations combined with phonon analysis and free-energy mapping techniques.

Model / system. The physical system is Lithium tantalate (LiTaO3), a ferroelectric perovskite oxide. The analysis models the competition between the FE and AFE states by calculating the free energy ($\Phi$) as a function of the electric displacement field (D).

Key observables. Free energy minima depths for FE and AFE phases, the critical electric displacement D_c, and the soft mode frequencies (A_2u and A_2g).

Important parameters / regimes. Boundary conditions (Short-Circuit vs. Open-Circuit), electric displacement D, and the comparison to LiNbO3 parameters.

Assumptions / limitations. The calculations utilize DFT with the local density approximation (LDA) and incorporate the depolarization energy term to account for boundary effects.

Figures summary. Figures illustrate the atomic structure and eigenvectors of the soft modes, and show the free energy ($\Phi$) landscapes for FE and AFE phases under different boundary conditions and as a function of D.

Abstract

Ferroelectric and antiferroelectric phases of LiTaO$_3$ compete under different electric boundary conditions. First-principles density-functional calculations show that the high-symmetry reference structure supports two relevant unstable $Γ$ modes: a polar $A_{2u}$ mode at $181i$ cm$^{-1}$ that condenses into the ferroelectric (FE) phase, and an antipolar $A_{2g}$ mode at $103i$ cm$^{-1}$ that condenses into the antiferroelectric (AFE) phase. Under short-circuit conditions the FE phase is the global minimum, with a well depth of $\approx 144$ meV. Under open-circuit conditions the FE phase is destabilized by the unscreened depolarization field and the AFE phase becomes the ground state, with a well depth of $\approx 19$ meV. A weakly unstable longitudinal-optic mode at $48.3i$ cm$^{-1}$ yields a well of only $\approx 0.24$ meV and is thermodynamically irrelevant. Mapping the free energy versus electric displacement $D$ locates a second-order FE$\leftrightarrow$AFE transition at $D_c=0.051$ C/m$^2$, lower than the corresponding $0.07$ C/m$^2$ in LiNbO$_3$ and therefore more accessible experimentally.

Abstract

Despite significant progress in the study of higher-order topological insulators (HOTIs), the chiral $C_4\mathcal{T}$-protected HOTI has remained elusive in electronic materials, where $C_4\mathcal{T}$ denotes the product of a four-fold rotation and time-reversal symmetry. Finally, we identify promising material classes to realise our proposal. Our results establish collinear altermagnetism as a route to intrinsic chiral higher-order topology and open a new path toward the discovery of $C_4\mathcal{T}$-protected HOTIs in real materials.

Gauge invariance, collective modes, and the justification of normal-state subtraction in Dirac superconductors

Summary. This theoretical work addresses the ambiguity in calculating the electromagnetic response of Dirac superconductors by investigating the role of vertex corrections. The authors demonstrate that the Normal-State Subtraction (NSS) procedure is rigorously justified because the vertex correction exactly restores gauge invariance in the static limit. This provides a crucial microscopic foundation for a widely used approximation in superconducting theory.

Why it may be interesting. While focused on superconductivity, the rigorous application of gauge invariance constraints via vertex corrections and the justification of a subtraction scheme (NSS) is a fundamental theoretical technique applicable to many interacting quantum systems.

Detailed structure

Main problem. The paper aims to microscopically justify the use of Normal-State Subtraction (NSS) when calculating the gauge-invariant electromagnetic response in Dirac superconductors.

Main result. The vertex correction exactly cancels the bare longitudinal response with NSS in the static long-wavelength limit, satisfying the required gauge invariance condition. This confirms that NSS is a valid theoretical procedure for this system.

Method. The authors use linear response theory, solving the Bethe-Salpeter equation, and analyzing the electromagnetic response kernel in the static, long-wavelength limit.

Model / system. The system studied is a Dirac superconductor, modeled using a massive-Dirac Hamiltonian with s-wave pairing. The analysis involves calculating the current-current correlation function via the Kubo formula.

Key observables. Longitudinal ($\Phi_L$) and transverse ($\Phi_T$) components of the electromagnetic response kernel, and the Meissner weight.

Important parameters / regimes. Static long-wavelength limit ($\omega=0, q o 0$), superconducting gap ($\Delta$), and the normal-state response ($\Phi_N$).

Assumptions / limitations. The analysis assumes the UV regularization term can be treated as an additive contribution, and it focuses on the static, long-wavelength limit to enforce gauge invariance.

Figures summary. Not specified in the notes.

Paper structure. The paper develops the full response kernel by decomposing it into bare, UV regularization, and vertex correction terms. It then analyzes the longitudinal and transverse components separately, showing how the vertex correction enforces gauge invariance when NSS is applied.

Abstract

In Dirac superconductors, the unbounded spectrum of low-energy Dirac models is known to give rise to unphysical interband contributions from deep-lying states to the electromagnetic response. To eliminate these contributions, normal-state subtraction (NSS), in which the normal-state response is subtracted from the superconducting-state response, has been widely employed. However, the relation between NSS and a gauge-invariant electromagnetic response, particularly the role of the vertex correction required by the Ward identity, has remained unclear. In this work, we consider a massive-Dirac model with $s$-wave pairing and analytically investigate the electromagnetic response at zero temperature by solving the Bethe--Salpeter equation and incorporating the collective-mode contribution to the electromagnetic vertex.
