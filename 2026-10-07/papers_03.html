Modular Neural Decoder for Surface Code Memory and Logic on Superconducting Processors

Authors: Moritz Lange, Ole Fjeldså, Gustaf Jonasson Johansson, Mats Granath
Type: both · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.03869v1

Summary. This paper presents a modular neural decoder designed to solve the challenge of making quantum error correction decoders portable across different hardware and logical operations. By using a reusable graph-recurrent architecture, the decoder successfully outperforms classical methods like MWPM on real superconducting hardware for memory, stability, and lattice surgery tasks. This demonstrates a significant step toward fault-tolerant quantum computation.

Why it may be interesting. The focus on hardware-agnostic, modular decoding techniques is crucial for scaling quantum computation, providing a blueprint for robust error mitigation across diverse physical implementations.

Detailed structure

Main problem. Developing a quantum error correction (QEC) decoder that is portable across different hardware platforms, noise conditions, and various logical operations beyond standard memory decoding.

Main result. The modular decoder outperforms Minimum-Weight Perfect Matching (MWPM) on real superconducting hardware for memory, stability, and lattice surgery tasks, demonstrating portability across different code observables.

Method. The authors introduce a modular graph-recurrent decoder architecture, which is pretrained in simulation and fine-tuned to hardware using a common pipeline.

Model / system. The work focuses on superconducting processors implementing the surface code. The decoder is designed to handle syndrome measurements from memory tracking, X-type stability checks, and ZZ-merge lattice surgery.

Key observables. Logical observable preservation ($Z_L$), inferred stabilizer products ($\prod X$-stabilizers), and the decoded correlation outcome of lattice surgery (ZZ parity).

Important parameters / regimes. Code distances ($d=3, 5, 9$), measurement error rates (tunable), and the specific type of logical operation being measured.

Assumptions / limitations. The decoder assumes a renormalization-style decomposition of the lattice and that the input syndrome graph structure can be kept consistent across different experimental settings.

Figures summary. Figures illustrate the surface code patches and their spacetime representations for Memory-Z, X-type Stability, and ZZ-merge lattice surgery, showing how the single decoder handles these different physical scenarios.

Paper structure. The paper progresses by first establishing the need for portable decoders, introducing the modular GNN-RNN architecture, and then validating its performance across three increasingly complex tasks: basic memory decoding, continuous stability monitoring, and complex lattice surgery operations.

Abstract

Neural decoders for quantum error correction have achieved high accuracy on surface code memory experiments, but practical fault-tolerant computation requires decoders that transfer across devices, noise conditions, and logical operations. We introduce a modular graph-recurrent decoder designed for this setting. Built from reusable local syndrome encoders, it is pretrained in simulation and fine-tuned to hardware using a common pipeline, with only lightweight spatial aggregation adapted between experiments. The decoder performs competitively on conventional memory benchmarks, outperforming minimum-weight perfect matching (MWPM) at distances 3 and 5 on an IBM Nighthawk-generation processor and closely approaching AlphaQubit on Google's below-threshold hardware data. We then test the framework in two settings beyond memory decoding on the same IBM device. First, in an $X$-type stability experiment, we continuously tune the effective measurement error rate using a variable pre-readout rotation and train a single decoder jointly across the resulting noise range. It matches or outperforms MWPM across the sweep without requiring a separately calibrated decoder for each setting. Second, we decode a $ZZ$-merge lattice-surgery experiment between two distance-3 surface-code patches, improving the decoded correlation between the merge outcome and the final $ZZ$ parity relative to MWPM on real hardware. Together, these experiments demonstrate neural decoding that is portable not only across hardware, but also across qualitatively different surface code observables and logical operations, using models trainable on single-GPU academic resources.

The collapse time of weak measurement on $N$ entangled sites

Summary. This theoretical paper calculates the time required for weak measurements to collapse an initial superposition of $N$ quantum states down to a single outcome. It rigorously proves that this collapse time scales linearly with $\ln N$, correcting previous theoretical estimates. The results are significant for understanding the dynamics of measurement back-action in entangled quantum systems.

Why it may be interesting. This work provides precise scaling laws for measurement-induced collapse in entangled quantum systems, which is crucial for understanding measurement back-action in quantum computation and quantum sensing.

Detailed structure

Main problem. The paper determines the time scale required for local weak measurements to collapse the occupation probability of an initial superposition of $N$ alternatives down to a single occupied site.

Main result. The collapse time $T_N$ scales asymptotically as $T_N / \ln N o 1/2$ in $L^1$, correcting previous estimates of double-logarithmic scaling.

Method. The analysis uses stochastic differential equations for the occupation weights, martingale theory, and bounding techniques derived from information theory (entropy).

Model / system. The system models a single excitation initially superposed equally among $N$ entangled sites, where local weak measurements continuously monitor the occupation probability of each site.

Key observables. Collapse time $T_N$, occupation probabilities $w_n(t)$, and the system entropy $H(t)$.

Important parameters / regimes. The number of sites $N$, the confidence threshold $\delta$, and the characteristic measurement time $ au_m$.

Assumptions / limitations. The initial occupation probabilities are assumed to be equal ($1/N$), and the analysis relies on the weights being bounded martingales.

Figures summary. Figure 1 compares simulated Gaussian means against theoretical curves, showing the proposed logarithmic fit has a significantly lower Root-Mean-Square Deviation than previously published double-logarithmic curves.

Paper structure. The paper develops the evolution equations for the weights, establishes bounds on the collapse time using martingale theory, proves the asymptotic scaling law, and finally addresses the reliability of the first crossing event.

Abstract

We determine the time required for local weak measurements to collapse to one occupied site in an initial superposition of $N$ alternatives in the model of PRA 111, 032217 (2025). For equal initial occupation probabilities and a fixed confidence threshold $1-δ$, we prove $T_N/\ln N\to1/2$ in $L^1$, with time measured in units of the characteristic measurement time $τ_m$ of each detector. We also connect the asymptotic stabilization theorem of that work to a finite measurement: the first site to reach $1-δ$ is the eventual outcome with conditional probability exactly $1-δ$. The result corrects the previously proposed double-logarithmic asymptotic scaling. The finite-range numerical fit does not determine a constant asymptotic correction or a precise finite-$N$ law.

Fragmented and symmetry-restored condensates in a three-site Bose ring: exchange versus umklapp

Authors: A. Siddiki
Type: theory · Category: quantum gases · PDF: https://arxiv.org/pdf/2610.05469v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: 🔥 analog quantum simulation 4/5

↔ Scroll figures horizontally

Summary. This work studies interacting bosons on a three-site ring to distinguish between symmetry-restored condensates and fragmented quantum states. By comparing models with and without Umklapp scattering, the authors show that Umklapp terms stabilize the condensate, while the absence of these terms allows the system to enter a highly fragmented state under specific interaction conditions.

Why it may be interesting. It provides a detailed, quantitative comparison of how different symmetry-breaking mechanisms (exchange vs. Umklapp) dictate the nature of quantum ground states in interacting bosonic systems, which is highly relevant to understanding superfluidity and quantum magnetism in cold atom setups.

Detailed structure

Main problem. The paper investigates the transition between different ground states (condensate vs. fragmented state) in a Bose ring, specifically comparing the roles of 'exchange' versus 'Umklapp' scattering mechanisms.

Main result. The presence of Umklapp scattering stabilizes the standing wave condensate, leading to a number-squeezed state, whereas its absence allows for a transition to a robustly fragmented Fock state when interactions are attractive.

Method. The study employs exact diagonalization up to N=400 and analyzes the large-N limit using coherent-state functional minimization and Bogoliubov theory.

Model / system. The system is $N$ bosons on a three-site ring, modeled by a Hamiltonian involving nearest-neighbor hopping, density-assisted hopping, and on-site interactions, analyzed via momentum modes $q \in \{0, \pm 1\}$.

Key observables. Fragmentation ($F$), ground-state occupations ($\langle n_q angle/N$), and the critical coupling ($\lambda_c$) determining the phase transition.

Important parameters / regimes. The number of bosons ($N$), the coupling strength ($\lambda$), and the relative importance of Umklapp versus exchange terms.

Assumptions / limitations. The analysis relies on comparing exact diagonalization results with large-N mean-field approximations (Gross-Pitaevskii theory).

Figures summary. Figures illustrate ground-state occupations vs. coupling, comparisons between exact and variational energies, and the dependence of critical couplings on $1/N$ for both Umklapp and non-Umklapp cases.

Paper structure. The paper systematically analyzes the Hamiltonian, first establishing the general transition, then isolating the 'no-umklapp' case to study the exchange mechanism, and finally including umklapp terms to contrast the resulting symmetry-restored condensate with the fragmented state.

Abstract

We study $N$ bosons on a three-site ring with nearest-neighbour hopping, density-assisted hopping of the opposite sign, and an on-site interaction, written equivalently as three momentum modes $q=0,\pm1$ with a channel-dependent quartic vertex. As the density-assisted term grows it inverts the band, and exact diagonalisation up to $N=400$ shows a first-order ground-state transition from the $q=0$ condensate to a state with $\avg{n_{+1}}=\avg{n_{-1}}\simeq N/2$; the avoided-crossing gap closes faster than exponentially with $N$. In its symmetric eigenstates this state is fragmented in the Penrose-Onsager sense, and at leading order in $N$ it has the energy of a Gross-Pitaevskii (GP) standing wave, as expected for a few-mode mean-field system. We distinguish two cases by switching off umklapp scattering, which is available because $2\cdot(+1)\equiv-1$ on three sites, and by varying the on-site interaction. Without umklapp, $n_{+1}-n_{-1}$ is conserved, the eigenstates form a rotor tower whose lowest member is a fragmented Fock state, and the transition leads to fragmentation exactly when the $\pm1$ interaction is attractive, as predicted by Nozières' exchange argument with the sign of the interaction reversed; otherwise the system forms a single current-carrying condensate. With umklapp, the standing wave is pinned to three positions, the three momentum sectors become degenerate exponentially in $N$, and coherent admixture of the $q=0$ mode stabilises the standing wave over a wider range; the exact ground state is then a number-squeezed, momentum-projected standing-wave condensate rather than a robustly fragmented state.

On State Distinguishing Without Inverse Queries

Authors: Emma Wang, Joseph Carolan, Andrew M. Childs
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.05389v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: 🔥 quantum measurements 4/5

↔ Scroll figures horizontally

Summary. This paper analyzes the quantum state distinguishing problem under the constraint of forward-only access to unitary evolution. It proves that in the discrete setting, distinguishing states requires a quadratic number of queries ($\Omega(\epsilon^{-2})$). However, by adapting the problem to a continuous-time model and employing Quantum Zeno dynamics, the authors achieve a superior scaling of $O(\epsilon^{-1})$ total evolution time.

Why it may be interesting. The work provides concrete, quantifiable results on the limitations of quantum measurement protocols when time-reversal symmetry is broken, which is crucial for understanding physical processes like irreversible measurements or open quantum system dynamics.

Detailed structure

Main problem. The paper investigates the minimum number of forward-only queries required to distinguish between two quantum states or unitary operations, contrasting this with scenarios where inverse queries are available.

Main result. In the discrete-time setting, distinguishing states requires $\Theta(\epsilon^{-2})$ queries, while a continuous-time variant can be solved with a better $O(\epsilon^{-1})$ total evolution time using Quantum Zeno dynamics.

Method. The authors employ direct hybrid arguments for lower bounds in the discrete case and utilize Quantum Zeno dynamics combined with projections to construct an efficient upper bound for the continuous-time analogue.

Model / system. The model involves distinguishing between two states generated by unknown unitaries ($U$ vs $V$) or Hamiltonians ($H$), operating in high-dimensional Hilbert spaces. The core constraint is the inability to perform inverse queries.

Key observables. The separation parameter $\epsilon$, the required number of queries (discrete), and the total evolution time (continuous).

Important parameters / regimes. The dimension $d$ of the system, and the separation $\epsilon \in (0, 1]$.

Assumptions / limitations. The primary assumption is the forward-only access to the unitary evolution or Hamiltonian, which models physical processes that cannot be reversed.

Paper structure. The paper first establishes the lower bound for the discrete-time setting using a direct hybrid argument. It then presents an upper bound for the continuous-time setting using Quantum Zeno dynamics to reduce the problem to a 2D subspace, achieving a better scaling.

Abstract

In the quantum state distinguishing problem, an algorithm is given copies of a state $|ψ\rangle$ or $|φ\rangle$ separated by trace distance $\varepsilon$, and tasked with deciding which is the case. It is a standard result that $Θ(\varepsilon^{-2})$ copies are required, while having access to a unitary state preparation oracle and its inverse improves this to $Θ(\varepsilon^{-1})$ queries. We study the intermediate case with forward-only access, capturing scenarios where the oracle is a physical process that cannot be reversed. Tang and Wright recently showed that distinguishing a known state from an \emph{unknown} close state requires $Ω(\varepsilon^{-2})$ forward queries in high dimension; we strengthen this result by proving the same bound even when both states are known, as in the state distinguishing setting. Moreover, our lower bound uses a direct hybrid argument, avoiding advanced compressed oracle techniques used in the prior work. In contrast, we give a dimension-independent algorithm solving a continuous-time variant of state distinguishing with only $O(\varepsilon^{-1})$ total forward evolution time. The algorithm uses quantum Zeno dynamics to confine evolution to a known two-dimensional subspace. Thus, a quadratic advantage survives without inverse access for a natural continuous-time analogue of state distinguishing.

Quantum 1-PCA with Pauli Measurements in Nearly Linear Time

Authors: Dutch Hansen, Jerry Li
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2610.06808v1

Summary. This work presents an efficient quantum algorithm for performing Principal Component Analysis on unknown $n$-qubit mixed states using only single-qubit Pauli measurements. By developing a structured Pauli sampling scheme and a recursive subspace projection method, the authors achieve near-optimal complexity bounds. This is significant for quantum characterization protocols where measurement resources are limited.

Why it may be interesting. The development of efficient, measurement-based algorithms for state characterization, particularly achieving near-exponential speedups in complexity, is crucial for practical quantum characterization protocols.

Detailed structure

Main problem. The paper addresses the quantum Principal Component Analysis (PCA) problem: recovering a classical description of the leading eigenvector of an unknown $n$-qubit mixed state $ ho$ using only non-adaptive, single-qubit Pauli measurements.

Main result. They provide an algorithm achieving near-optimal complexity, $ ilde{O}(2^n/\epsilon)$, for both copy count and runtime when the spectral gap is constant and accuracy matches noise levels. This generalizes prior work by handling mixed states.

Method. The technique involves recursively constructing low-dimensional subspaces that approximate the target eigenvector, coupled with a novel structured Pauli sampling scheme for fast, batched computation of projected Pauli matrices.

Model / system. The system is an unknown $n$-qubit mixed state $ ho$. The analysis is rooted in quantum information theory, utilizing Pauli measurements to characterize the state's leading eigenvector.

Key observables. The leading eigenvector $|\psi angle$, the spectral gap $\Delta = \lambda - \lambda_2$, and the fidelity $|\langle\hat{\psi}|\psi angle|^2$.

Important parameters / regimes. The qubit number $n$, the target error $\epsilon$, and the noise parameter $\eta = \max(1 - \lambda, \epsilon)$.

Assumptions / limitations. The analysis relies on bounding error propagation across recursive subspace projections and assumes the existence of a structured Pauli sampling scheme for efficiency.

Figures summary. Not specified.

Paper structure. The paper details the overall algorithm (Algorithm 4) which iteratively prunes the state space. It builds upon techniques for estimating projected Pauli matrices using structured sampling and robust estimation methods like Lepskii's method.

Abstract

We consider the problem of quantum 1-PCA: given copies of an unknown $n$-qubit mixed state, recover a classical description of its leading eigenvector. Our goal is to do so using non-adaptive and single-qubit measurements. For an $n$-qubit state with top eigenvalue $λ$ and spectral gap at least $Δ> 0$, we give an algorithm that recovers the leading eigenvector to fidelity at least $1 - \varepsilon$ with high probability using $\tilde{O}\left( {2^n \cdot η^2} / {Δ^3 \varepsilon^3}\right)$ copies and $\tilde{O}((2^n/Δ\varepsilon) \cdot \operatorname{poly}(η/Δ\varepsilon))$ time, where $η= \max (1 - λ, \varepsilon)$. All of our measurements are non-adaptively chosen, and performed in single-qubit Pauli bases. When the spectral gap is constant and the desired accuracy is comparable to the noise level, i.e. $\varepsilon = Ω(η)$, our runtime and copy complexity become $\tilde{O} (2^n / \varepsilon)$. This generalizes the guarantees of Grewal et al. [arXiv:2601.04444], who achieved similar rates, but under the assumption $η= 0$, i.e., that the state was pure. Our results show that the same rates hold in the presence of state misspecification, up to polylogarithmic factors. From a technical perspective, our algorithm works by recursively constructing low-dimensional subspaces that approximately preserve the target eigenvector. To achieve nearly linear runtime dependence on the dimension of the Hilbert space, we develop a novel structured Pauli sampling scheme that enables fast batched computation of exponentially many projected Pauli matrices.

Record consistency under repeated readout and apparatus composition

Summary. This theoretical paper analyzes the robustness of no-signalling constraints when an experimental apparatus is extended through repeated measurements or network connections. Using advanced mathematical tools, the authors establish necessary conditions—beyond simple marginal constraints—that must hold for the joint record law to remain consistent. The findings provide a detailed framework for understanding the limitations of local realism in complex measurement settings.

Why it may be interesting. This work provides rigorous mathematical constraints on how local no-signalling principles must be extended to describe complex, multi-stage quantum or retrocausal measurements, which has implications for understanding measurement theory beyond simple Bell tests.

Detailed structure

Main problem. The paper investigates the necessary conditions for an apparatus to maintain the joint law of its accessible records when subjected to complex extensions like repeated readout, network composition, or reuse, even if initial isolated outcome probabilities satisfy no-signalling constraints.

Main result. The study derives specific, non-trivial conditions—such as angle-independent responses for two readouts or full non-negative rank for correction matrices—that must accompany marginal no-signalling when extending an apparatus to richer records.

Method. The authors employ a conditional-record criterion, utilizing tools from Fourier analysis, total variation distance bounds, and developing four explicit mathematical models to test these extensions.

Model / system. The analysis focuses on retrocausal models, specifically using a wrapped-Cauchy retrocausal source and developing criteria for apparatus extension across different measurement scenarios (e.g., Bell junctions, continuous readouts).

Paper structure. The paper proceeds by defining the source/apparatus specification, then detailing the conditional-record criterion, and finally applying this criterion to four distinct extension scenarios: repeated readout, network composition, and variable-width source laws.

Abstract

No-signalling constraints on isolated outcome probabilities do not determine whether an apparatus preserves the joint law of its accessible records under repeated readout, network composition, or reuse. We study these extensions through a conditional-record criterion and four explicit models. For a wrapped-Cauchy retrocausal source, protection under two conditionally independent continuous readouts forces an angle-independent response; three readouts suffice without continuity. A finite angular-bandwidth assumption gives a quantitative leakage bound, whereas continuity alone gives no uniform stability. At a specified two-source Bell junction, the required correction matrix has full nonnegative rank on every even uniform angular grid. A Gaussian controller can cancel branch-mass dependence while leaving a distinguishable joint record, for which we derive exact noise and law-change tradeoffs. Finally, a fixed singlet with shared classical noise reproduces the variable-width isolated outcome family, but retained and refreshed controllers generate different temporal statistics. We prove a finite-resource obstruction and construct positive finite-controller approximations. Numerical studies comprising 8.3 million independent simulated histories support the model-specific predictions. Together, the results identify conditions that must accompany marginal no-signalling when extending an apparatus to richer records and interventions.

Abstract

Self-testing certifies quantum states and measurements from observed correlations alone, without requiring a description of the devices that produce them. In this work we establish, to the best of our knowledge, the first robust self-test of the full continuous family of measurements generated by Majorana operators. We achieve this by showing that the Grothendieck game, a two-player nonlocal game in which the players receive directions on a sphere and return binary answers, is a self-test of Majorana observables. That is, any near-optimal performance certifies an entire continuously parameterized family of quantum measurements. We further extend this certification to products of Majorana observables, obtaining a robust self-test of the spin representation of the continuous pin group.

Abstract

Abstract

Photon loss makes Gaussian boson sampling easier to simulate classically. A standard approach replaces the lossy input by classical light, and it stays accurate while the mean number of surviving photons grows no faster than the square root of the number $N$ of squeezed inputs at fixed squeezing and accuracy. We prove that this scale is a limit of replacement by classical light. For explicit interferometers, no state with a nonnegative Glauber--Sudarshan $P$ representation, Gaussian or not and however correlated, keeps the error in the photon count distribution small beyond this scale. We then surpass this limit by approximating the detection instead of the input. The sampler evolves the state exactly between detections and, after each detection, replaces the conditional state by a Gaussian with the same covariance. For every interferometer its total variation error is $O(Nη^3)$ at polynomial expected cost, where $η$ is the photon survival probability. The mean surviving photon number can therefore grow as $N^{2/3}$ at fixed accuracy. A separate pair construction reaches $N^{3/4}$ when every input mode is equally squeezed.
