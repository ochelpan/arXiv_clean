Robust Device-Independent Certification of Boolean-Phase Gates

Authors: Yunguang Han, Xingyuan Bu, Aleksandra Gočanin, Jiabing Yuan
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2609.09836v1
Analysis basis: full PDF text, analyzed in chunks Topic relevance: quantum measurements 2/5

Summary. This paper presents a robust, device-independent method to certify the fidelity of Boolean-phase quantum gates. It achieves this by transforming the gate's phase dependence into classical constraints evaluated via Bell inequalities using only local measurements. The resulting fidelity bound is explicit and uniform over all Boolean functions, providing a powerful tool for quantum device characterization.

Why it may be interesting. The technique of translating gate-specific quantum information into classical constraints on local measurements is highly generalizable and provides a powerful tool for verifying quantum hardware fidelity in a resource-efficient manner.

Detailed structure

Main problem. The paper develops a robust, device-independent certification scheme for Boolean-phase gates, addressing the issue that self-testing the output Choi state alone is insufficient.

Main result. They derive a closed-form Choi-fidelity bound for an effective n-qubit channel by combining an identity test and a gate-output test in an independent-source network.

Method. The core method involves using Boolean differentiation to convert gate-dependent phase information into classical signs, which are then evaluated using Bell tests built from CHSH blocks with only local measurements.

Model / system. The system under study is the Boolean-phase gate, defined by a Boolean function f on n qubits, represented as a diagonal unitary matrix. The certification is performed using an independent-source network structure.

Key observables. The normalized Choi state, the Bell expression $B_f$, and the extracted-state squared fidelity $F^2( ho_{ ext{ext}}, |\Psi_f angle\langle\Psi_f|)$.

Important parameters / regimes. The Bell deficit $\epsilon$, which quantifies the deviation from maximal violation, and the number of qubits $n$.

Assumptions / limitations. The analysis assumes the ability to combine an identity test and a gate-output test using the same physical observables, and that the B-side extraction preserves every physical Z-measurement exactly.

Figures summary. Figure 1 illustrates the Boolean-derivative scoring for a Bell term, mapping outcomes to bits and the derivative sign. Figure 2 illustrates the independent-source network structure used for the combined test.

Paper structure. The paper first introduces the problem and the Boolean-derivative technique. It then establishes self-testing bounds (Theorem 1) and derives a robust fidelity bound (Theorem 2) using an independent-source network. Finally, it applies this framework to the CCZ gate using a joint six-party analysis.

Abstract

Device-independent certification of a quantum gate requires the input and output tests to identify the same reference qubits. Self-testing the output Choi state alone does not guarantee this consistency. We develop a robust certification scheme for Boolean-phase gates, a broad family of computational-basis diagonal gates specified by Boolean functions. Boolean derivatives convert the target-dependent phase information into classical signs that can be evaluated from local measurement outcomes. This leads to Bell tests built from CHSH blocks using two binary measurements per party and no entangling measurements. At maximal violation, the tests self-test the normalized Choi state and the measured observables. Away from the maximum, they give an explicit affine lower bound on the extracted-state squared fidelity that is uniform over all Boolean functions and valid in arbitrary local dimensions. We then combine an identity test and a gate-output test in an independent-source network in which the reference devices use the same physical observables, obtaining a closed-form Choi-fidelity bound for an effective \(n\)-qubit channel. For CCZ, a joint six-party analysis gives a stronger robustness bound without changing the Bell expression or measurement settings. The construction shows how the algebraic structure of a gate can shift target-dependent information from quantum measurement design to classical processing of local outcomes.

Abstract

We study the two-weight decision version of quantum approximate counting: given oracle access to $x\in\{0,1\}^N$, distinguish $|x|=M$ from $|x|=M+Δ$ with success probability $1/2+ζ$. Using the multiplicative adversary method, we prove $Ω\left(\max\left\{ζ\sqrt{(N-M)(M+Δ)}/Δ,\sqrt{ζN/Δ}\right\}\right)$. The same parameter dependence follows from the polynomial-method characterization of the two-layer symmetric function by Podder, Yao, and Ye. Our contribution is a multiplicative-adversary derivation that tracks the progress produced by individual oracle queries. For the first term, after complementing the input if necessary, we assume $M+Δ\le N-M$. We use the Hamming-layer subspaces from the eigenspace method of Ambainis, Spalek, and de Wolf and compose their adjacent-layer unitary maps to relate the two nonadjacent promise layers. After fixing the queried coordinate, the analysis block-diagonalizes into four-dimensional subspaces. An exact calculation of the one-query progress ratio gives the first lower bound. The same estimate also implies $\left\|(I-\widehatΠ_{\mathrm{bad}})\lvertΨ^T\rangle\right\|^2=O\left(T^2Δ^2/((N-M)(M+Δ))\right)$ for the coherent input superposition used in the adversary argument. For the second term, we prove directly using a three-eigenvalue multiplicative adversary that unique OR on $n$ bits with success probability $1/2+ζ$ requires $Ω(\sqrt{ζn})$ queries, and then reduce unique OR to the two-weight counting problem.

Summary. This work analyzes the stabilizer Rényi entropy (SRE) of the Dyck-Fredkin spin chain under a deformation parameter $t$. The SRE reveals three distinct scaling regimes—linear, logarithmic, and constant—depending on $t$. This demonstrates that non-stabilizerness can serve as a sensitive diagnostic tool, potentially offering new insights into quantum many-body criticality compared to entanglement entropy.

Why it may be interesting. The clear distinction in scaling behavior ($\Theta(N)$ vs $\Theta(\log N)$ vs $\Theta(1)$) based on a simple parameter $t$ provides a powerful, quantifiable tool to characterize different types of quantum criticality beyond standard entanglement measures.

Detailed structure

Main problem. The study investigates the scaling behavior of non-stabilizerness, quantified by the stabilizer Rényi entropy (SRE), in quantum many-body systems to probe their critical properties.

Main result. The SRE exhibits distinct scaling behaviors ($\Theta(N)$, $\Theta(\log N)$, or $\Theta(1)$) depending on the deformation parameter $t$, suggesting non-stabilizerness offers a unique diagnostic tool distinct from entanglement entropy.

Method. The authors employ numerically exact finite-size calculations and asymptotic analysis on the SRE, which is derived from the ground state of the spin chain.

Model / system. The system analyzed is the spin-1/2 Dyck-Fredkin chain and its $t$-deformation, a local frustration-free model whose ground state is a weighted superposition of Dyck-path states.

Key observables. Stabilizer Rényi entropy ($\alpha$-SRE), entanglement entropy, and the spectral gap.

Important parameters / regimes. The deformation parameter $t$, which dictates three distinct scaling regimes: $t<1$, $t=1$, and $t>1$.

Abstract

The stabilizer Rényi entropy is a quantitative measure of non-stabilizerness, or magic, and has typically been found to scale extensively with system size $N$ (i.e., $Θ(N)$) for a variety of many-body quantum states. In this note, we study the stabilizer Rényi entropy of the ground state of the spin-$\frac{1}{2}$ Dyck-Fredkin chain and its $t$-deformation, a local frustration-free model with unusual spectral-gap scaling. Exploiting the combinatorial structure, we carry out numerically exact finite-size calculations, which indicate asymptotic behavior depending on $t$: $Θ(N)$ for $t<1$, $Θ(\log N)$ at $t=1$, and $Θ(1)$ for $t>1$. The scaling at $t=1$ could be another manifestation of the unconventional criticality of the model, while the contrast with the behavior of the entanglement entropy suggests that non-stabilizerness might provide a new window into quantum many-body systems.

Unbounded degree overhead for Alice-conditioned quantum Bell certificates

Authors: Fumin Wang
Type: theory · Category: quantum information and computing · PDF: https://arxiv.org/pdf/2609.10162v1

Summary. This paper rigorously analyzes the resource cost associated with certifying quantum Bell inequalities when the certification process is conditioned on a single measurement choice by Alice. It proves that this conditioning introduces an unbounded overhead in the required degree of the polynomial certificate compared to standard methods. The findings help separate the computational resources needed for different structural assumptions in quantum information theory.

Why it may be interesting. This work provides rigorous mathematical tools to quantify the computational complexity of verifying quantum nonlocality, which is fundamental to quantum information theory and device-independent security protocols.

Detailed structure

Main problem. The paper investigates the additional degree overhead required when certifying quantum Bell inequalities using certificates conditioned on a single measurement choice by Alice.

Main result. It proves that the required conditioned certification level grows unboundedly as the system approaches certain limits, separating the resource requirements of single-question conditioning from standard SOS degree bounds.

Method. The authors use Semidefinite Programming (SDP) relaxations formulated as Sum-of-Squares (SOS) polynomials, constructing explicit counterexamples using truncated positive functionals on the infinite dihedral group.

Model / system. The analysis focuses on quantum Bell inequalities, specifically the CHSH inequality, analyzed through the Navascués–Pironio–Acín (NPA) hierarchy and its specialized Alice-conditioned variants.

Key observables. The primary observables are the SDP values ($\omega_{std}^k$ vs. $\omega_{os}^k$) for standard and Alice-conditioned Bell certificates, and the resulting quantum-bound curve $\alpha(u)$.

Important parameters / regimes. Key parameters include the conditioning parameter $\alpha$, the certificate level $k$, and the distance $\epsilon$ to the endpoint tilt.

Assumptions / limitations. The analysis relies on comparing the required degree for exact certification against the standard degree, and distinguishing between exact closure and finite-tolerance numerical saturation.

Figures summary. Figure 1 illustrates the unbounded cost, showing the required conditioned degree diverging from the standard degree as the distance to the endpoint decreases.

Paper structure. The paper develops results by first showing the unbounded overhead (Theorem 1), then establishing continuous exact certification over an interval (Theorem 2), and finally refuting conjectures about fixed-level containment (Theorem 8.2).

Abstract

Requiring each sum-of-squares term to involve only one of Alice's measurement questions can impose an unbounded certification cost. In the simplest Bell scenario, we prove that no finite level of the Alice-conditioned NPA hierarchy contains all standard level-two Bell certificates. An explicit family of truncated positive functionals on the infinite dihedral group exceeds the tilted-CHSH quantum bound at every prescribed finite level, while a standard degree-two certificate is exact. A Fejer-weighted trace reduces positivity to a rank-one subtraction from a moving-average Gram matrix. The required conditioned level grows at least as $(2-α)^{-1/2}$ near the endpoint tilt. This bounds the degree of exact nice-SOS inputs to compiled-game soundness proofs. Consequently, no finite conditioned level certifies the entire optimal CHSH randomness tradeoff against quantum side information, although standard level two does. Away from the endpoint, we prove a sharp one-level cost throughout $α\in[13/10,3/2]$, using optimal-strategy kernels and exact Bernstein matrix positivity to certify a continuous interval. The results separate ordinary SOS degree from the resources keyed by single-question certificate structure.

Summary. This paper develops a general theory showing that deterministic energy harvesting (DEH) is governed by the symmetries of the source-harvester system. By applying Noether's theorem, the authors prove that a single symmetry can generate an infinite family of source states, all capable of performing the exact same energy transfer. This establishes a fundamental, symmetry-protected principle for quantum energy extraction.

Why it may be interesting. This work provides a powerful, fundamental constraint (symmetry protection) on non-equilibrium quantum processes like energy harvesting, connecting deep mathematical principles (Noether's theorem) to practical quantum engineering problems.

Detailed structure

Main problem. The paper seeks to determine the general theoretical conditions under which deterministic energy harvesting (DEH) is possible from fluctuating quantum sources.

Main result. It establishes that Noether's theorem provides a general principle: a continuous symmetry of the joint source-harvester dynamics guarantees that an entire orbit of source states can perform the same deterministic energy transfer.

Method. The authors employ Noether's theorem to link continuous symmetries (and conserved charges) to the existence of multiple source states that yield identical, deterministic energy transfer outcomes on the harvester.

Model / system. The system involves a coupled quantum source and harvester described by a Hamiltonian $H = H_h + H_s + H_{int}$. The analysis is generalized to include classical and phase-space dynamics.

Key observables. Deterministic energy transfer ($ ho_i^h o ho_f^h$), source asymmetry ($I(\sigma)$), and the conserved Noether charges ($Q_\alpha$).

Important parameters / regimes. The time evolution $ au$, the symmetry generators $R(g)$, and the source asymmetry $I(\sigma)$.

Assumptions / limitations. The primary assumptions for the main theorem are the existence of an exact Noether symmetry for the joint dynamics and the exact invariance of the harvester boundary states under this symmetry.

Figures summary. Figures illustrate how Noether symmetry generates orbits of source states that jointly achieve DEH, and show population dynamics for non-Abelian DEH protocols.

Paper structure. The paper progresses from defining DEH and identifying the role of symmetries, proving the main theorem using Noether's theorem, illustrating the concept with specific models (Jaynes-Cummings, XX chain), and finally generalizing the findings to other physical theories.

Abstract

We consider the general principles for when deterministic energy harvesting (DEH) is possible. DEH means absorbing energy from a fluctuating source without entropy being absorbed. We show that the symmetry structure of the source--harvester dynamics gives a general route beyond existing examples to identify DEH capable source states. Any continuous symmetry with a conserved Noether charge induces a source-side orbit of states that all implement the same deterministic harvester transition, provided the harvester boundary states are symmetry invariant. Consequently, one DEH capable source state with nonzero asymmetry between charge sectors can generate infinitely many simultaneously DEH capable source states. A Jaynes-Cummings model, a three-spin XX chain, and an SU(2) model illustrate the construction. We further extend Noether's theorem to generalised probabilistic theories and thereby generalise our main result. We further establish an asymmetry bound for harvesting, showing that source asymmetry cannot increase on average, while DEH saturates the bound exactly preserving asymmetry.

Summary. This paper compares two diagnostics, entanglement asymmetry and trace distance, to determine when they both accurately describe the symmetry restoration dynamics linked to the Quantum Mpemba Effect in spin systems. By analyzing charge versus permutation symmetries, the authors show that the reliability of energy-based measures depends strongly on the underlying symmetry structure. This clarifies the distinct physical information encoded by different quantum diagnostics.

Why it may be interesting. This work provides a rigorous theoretical framework for distinguishing between different types of quantum information measures (entanglement vs. energy-based) in non-equilibrium dynamics, which is crucial for understanding relaxation processes in complex quantum many-body systems.

Detailed structure

Main problem. The paper investigates the conditions under which conventional energy-based diagnostics, like the trace distance, accurately capture the symmetry-restoration dynamics associated with the Quantum Mpemba Effect (QME) when compared to entanglement asymmetry.

Main result. The diagnostic used depends critically on the symmetry structure: for charge symmetry, the trace distance effectively tracks entanglement asymmetry, but for permutation symmetry, a significant residual contribution causes them to evolve differently.

Method. The study combines numerical simulations with an analytical decomposition of the trace distance into symmetry-coherence and residual contributions to compare its dynamics against entanglement asymmetry.

Model / system. The analysis is performed on closed spin-1/2 quantum systems, utilizing Hamiltonians exhibiting different symmetries, specifically charge symmetry and permutation symmetry. Initial states are prepared as symmetry-breaking product states.

Key observables. Entanglement asymmetry ($\Delta S_A$) and Trace distance ($\Delta(\hat{ ho}_A)(t)$).

Important parameters / regimes. Symmetry-breaking parameters (e.g., tilt angle $ heta$ for charge symmetry; polar-angle difference $\Delta heta$ for permutation symmetry).

Assumptions / limitations. The analysis relies on decomposing the trace distance and comparing the time evolution of two distinct symmetry-breaking scenarios (charge vs. permutation).

Figures summary. Figures compare the time evolution of $\Delta S_A(t)$ and $\Delta(\hat{ ho}_A)(t)$ for different symmetry-breaking initial states, showing qualitative agreement for charge symmetry but divergence for permutation symmetry.

Paper structure. The paper first introduces the problem by comparing two diagnostics ($\Delta S_A$ vs. Trace Distance) in spin systems. Abstract

Understanding symmetry restoration in isolated quantum many-body systems is an important problem in nonequilibrium many-body quantum physics. Recent studies have shown that the quantum Mpemba effect can be characterized through entanglement asymmetry, where states with stronger initial symmetry breaking restore symmetry faster. However, it remains unclear whether conventional energy-based measures, such as the trace distance, capture the same phenomenon. We investigate this question in closed spin-$1/2$ quantum systems with different symmetries by analyzing the dynamics of symmetry-breaking initial states. Combining numerical simulations with an analytical decomposition of the trace distance into symmetry-coherence and residual contributions, we identify the conditions under which trace distance tracks entanglement asymmetry and reproduces the Mpemba--like behavior observed in it. For charge symmetry, the residual contribution is negligible, making the trace distance effectively governed by symmetry-sector coherences. In contrast, for permutation symmetry, a significant residual contribution leads to qualitatively different relaxation dynamics. Our results establish when conventional energy-based diagnostics reliably capture symmetry-restoration dynamics and clarify the distinct physical information encoded by entanglement asymmetry and trace distance.

Abstract

Summary. This work analyzes how excluded-volume geometry dictates the accessible configuration space for three hard squares, revealing a sharp separation in the allowed phase space at $\phi=3/5$. The study uses advanced simulation techniques to map out the transition between two distinct structural regimes, demonstrating how simple geometric rules can govern complex, many-body ordering signatures even in a minimal system.

Why it may be interesting. Although focused on classical hard-body physics, the concept of configurational space bottlenecks and emergent structure selection from minimal constraints is highly relevant to understanding phase transitions and ordering in complex quantum many-body systems.

Detailed structure

Main problem. The study investigates the configurational-space separation and the emergence of structure selection in a minimal system of three hard squares confined in 2D.

Main result. The system exhibits a clear separation in its allowed configurational space at a density $\phi_{sep}=3/5$, and local structure selection favors L-shaped arrangements characteristic of higher-density ordering.

Method. The analysis combines Monte Carlo simulations (MCMC) with uniform non-overlapping insertion sampling to probe configurational space connectivity and measure pressure.

Model / system. The model consists of three hard squares confined within a two-dimensional periodic box. The complexity arises from excluded-volume constraints governing particle interactions.

Key observables. Radial distribution functions $g(r)$, pressure ($eta P a^2$), local order parameter $d/a$, and the identification of two distinct configuration classes (Class I and Class II).

Important parameters / regimes. Packing fraction ($\phi$), the critical separation density ($\phi_{sep} = 3/5$), and the particle number ($N=3$).

Assumptions / limitations. The analysis assumes that the discrepancy between MCMC and uniform sampling is due to configurational space separation, and that the dilute-limit calculation can neglect correlations beyond pair excluded-volume constraints.

Abstract

Self-assembly of hard particles with diverse shapes gives rise to a rich variety of structures through excluded-volume constraints alone. Here we show that even a minimal system of three hard squares confined in a two-dimensional periodic box exhibits nontrivial configurational behavior relevant to structure selection. As the packing fraction increases, radial distribution functions obtained from Markov-chain Monte Carlo and uniform non-overlapping insertion sampling agree at low densities, deviate markedly over an intermediate range, and converge again at higher densities. Pressure measurements provide strong numerical evidence that the discrepancy originates from the separation of the allowed configurational space into two disconnected regions above a characteristic density. We identify the separation density as $φ_{\rm sep}=3/5$, construct explicit overlap-free transition pathways connecting the two regions immediately below it, and quantify their relative configurational-space volumes. At higher packing fractions, an approximately L-shaped arrangement of the particle centers becomes strongly favored over a staggered one, revealing a structural motif characteristic of tetratic and square-lattice ordering in larger hard-square systems. These results show that excluded-volume geometry can govern both configurational connectivity and local structure selection even in a three-particle system, revealing how signatures of many-particle self-assembly can already emerge in the few-particle limit.

The classical circular-string embedding is periodic and radially stable, but its two physical transverse polarizations experience time-dependent tidal potentials. Expanding the world-sheet action to quadratic order, we canonically quantize these modes and construct out-of-time-ordered correlator(OTOC) amplitudes from their unequal-time commutators. For the Ellis--Bronnikov wormhole, both polarizations exhibit finite intervals of approximately exponential OTOC growth associated with the first throat passage. The corresponding dimensionless rate measured with respect to physical time is positive over the parameter range studied and generally decreases as the probe energy is increased relative to the throat scale. In the global-monopole extension, increasing the solid-angle deficit narrows the band of locally amplifiable modes and suppresses the extracted rates; a sufficiently strong defect can nearly quench the radial signal, while the angular channel retains a polarization-dependent non-monotonic structure when the energy-to-throat-scale ratio is small. These quantities characterize finite-time dynamical sensitivity in the Gaussian fluctuation sector and should not be identified with asymptotic many-body chaos or a thermodynamic phase transition. Although the numerical analysis uses two representative wormhole geometries, the construction depends only on covariant world-sheet fluctuations and real-time commutators. It therefore provides a transferable, non-holographic framework for applying quantum-chaos diagnostics directly to quantum probes in curved spacetimes.

Abstract

Credit default prediction is a tabular classification problem in which modest gains in F1 translate directly into reduced financial exposure. We ask whether Instantaneous Quantum Polynomial-time (IQP) circuits can produce features that improve a classifier over both its raw classical baseline and Kernel PCA - the strongest unsupervised classical non-linear alternative - at an equal feature budget. The dataset provides 23 financial attributes per client; for an n-qubit circuit we select n of them, encode each as a rotation angle, and read 2n expectation values back out as new features. The motivation for using a quantum circuit is computational: an n-qubit IQP circuit runs in constant depth and encodes feature correlations in a 2^n-dimensional Hilbert space, whereas classical simulation of its exact output statistics scales exponentially in n. Using the UCI Default of Credit Card Clients dataset and five-fold cross-validation, we find that appending 16 IQP features (n = 8 qubits) to a Logistic Regression model raises F1 from 0.462 to 0.517 (+0.055, p < 0.0001). Kernel PCA, the next-best method, reaches only 0.493 at the same feature count; the gap survives Benjamini-Hochberg correction across 12 tests (p = 0.00007). No other classifier - Random Forest, SVM, XGBoost, or k-NN - benefits, which points to a linear-expressivity mechanism rather than a generic improvement. We also show that how the 8 input features are chosen matters: Random Forest importance-guided selection reaches F1 = 0.523, while encoding maximally uncorrelated features drops it to 0.496, demonstrating that the circuit amplifies informative structure rather than creating it from scratch.
